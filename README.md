# Racha dos Teimosos

Painel de estatísticas do racha: ranking da temporada, rodadas, goleiros, títulos, estatísticas históricas, comparação entre jogadores e fila dos coletes.

Link: https://deyvidmello.github.io/Racha-dos-Teimosos/

O painel é um único arquivo (`index.html`), gerado a cada rodada a partir da planilha do racha. Para atualizar, basta substituir o `index.html` pela versão nova.
